## 📚 Estructura del Curso

### Organización por Temas
Cada tema sigue la estructura:
```
XX-tema/
├── notas/              # Material teórico (LaTeX)
│   ├── capitulo.tex    # Capítulo del libro
│   └── debug.tex       # Para compilación rápida
├── src/                # Código de ejemplo
├── practicas/          # Prácticas de laboratorio
│   ├── practica_01/
│   └── practica_02/
├── tareas/             # Tareas para casa
└── tests/              # Tests automatizados
```

**Nota:** Las clases se imparten en pizarrón usando el libro como referencia.

## 📊 Sistema de Evaluación

### Rúbrica General
| Componente | Peso | Descripción |
|------------|------|-------------|
| **Exámenes Teóricos** | 30% | 2 parciales + 1 final |
| **Prácticas de Lab** | 40% | Implementaciones con tests automáticos |
| **Tareas** | 20% | Ejercicios teórico-prácticos |
| **Participación** | 10% | Asistencia y contribuciones |

### Exámenes Teóricos (30%)
- **Parcial 1** (10%): Temas 1-2 (Ordenamiento, Búsqueda)
- **Parcial 2** (10%): Temas 3-4 (Grafos, Árboles)
- **Final** (10%): Temas 5-7 + Integración

### Prácticas de Laboratorio (40%)
Cada práctica incluye:
- Especificación del problema
- Tests automatizados (GitHub Actions)
- Rúbrica de evaluación
- Fecha de entrega

| Práctica | Tema | Puntos |
|----------|------|--------|
| P1 | Bubble Sort, Merge Sort | 5 |
| P2 | Quick Sort, Heap Sort | 5 |
| P3 | Counting Sort, Radix Sort | 5 |
| P4 | Búsqueda Binaria | 5 |
| P5 | Grafos: BFS y DFS | 5 |
| P6 | Dijkstra | 5 |
| P7 | Árboles Binarios | 5 |
| P8 | Árboles AVL | 5 |

### Tareas (20%)
Ejercicios teóricos y análisis de complejidad.
- Entrega semanal
- Formato: PDF o Markdown
