# Demo de pull request

Este archivo lo subió el curso para que veas cómo se abre un PR a **tu** `main`.

1. Mergea este PR (botón verde).
2. Tu tarea/examen va en **otra** rama, otro PR, y **Reviewers → @NoSoyRo**.
3. Pedir review = entrega. Este PR dummy no cuenta.

Puedes borrar `.curso/` después.
