### Checklist de Publicación

#### Antes de cada clase:
- [ ] Preparar materiales a subir
- [ ] Verificar que los archivos estén completos
- [ ] Hacer `git status` para revisar cambios

#### Comando útil para ver qué falta:
```bash
git status
git diff --stat
```

#### Si necesitas revertir un cambio:
```bash
git checkout -- <archivo>  # Deshacer cambios locales
git reset HEAD~1           # Deshacer último commit (sin push)
```
